# 统一设置（v0.3.0）

此页对应 [v0.3.0 正式安装包](https://github.com/op7418/guizang-tv/releases/tag/v0.3.0)。从官方 v0.2.0 覆盖安装可保留原有偏好；首次使用仍默认为照片背景、纵向文字列表和每 5 分钟轮播。

列表右下角、Dock 右上角只保留「全部应用」「其他信号源」「设置」。壁纸统一在「设置 → 背景」中管理。

main 另有「时间与天气」和「实验性功能」分组，尚未进入 v0.3.0 安装包。见[天气说明](WEATHER.md)与 [Codex 实验](CODEX.md)。Codex 默认为关闭，需在「实验性功能 → Codex 对话」手动开启后显示首页入口；旧配对不自动启用。关闭保留配对并停止电视端连接，已发送的回答可能在电脑继续。

## 操作逻辑

设置按分组展开，左侧为选项，右侧复用真实首页布局作为预览。方向键只移动焦点，按确定才保存。勾选标记是当前已应用值，高亮底板是遥控器焦点。无需另点保存；返回逐层退出，并保留已经确认的修改。

壁纸是例外：移动焦点会同时更新右侧圆角首页预览和整个设置页的高斯模糊背景，但不保存、不改变真实首页。按确定才应用；返回取消候选预览和仍未完成的加载，保留最后一次应用的图片。加载或保存失败会提示，并保留已有设置。

## 分组

| 分组 | 可设置内容 |
| --- | --- |
| 背景 | 照片、浅色、深色；照片模式下进入壁纸和轮播 |
| 布局 | 纵向列表、横向 Dock；应用和右侧操作分别选择文字、图标、图标＋文字 |
| 字体 | 轻盈、标准、衬线；列表字号小、标准、大 |
| 选中样式 | 文字高亮、毛玻璃；材质柔和、浓雾、清透；未选中项淡化程度 |
| 首页内容 | 1–9 个入口；添加、上移、下移、从首页隐藏；本次编辑内可撤销 |
| 电视与启动 | 原有开机自动进入开关、电视系统设置、小米原桌面 |

## 开发版：渐变时长

以下新增能力位于 main 开发版，尚不包含在上面链接的 v0.3.0 正式 APK 中。

照片背景开启轮播后，「设置 → 背景」在「轮播」下方显示同级入口「渐变时长」。可选 0.7–1.5 秒，步长 0.1 秒；默认保留原有的 0.7 秒。选择后立即保存，下一次切换使用该时长。固定壁纸或纯色背景时隐藏该入口，但保留已选时长。

渐变时长只影响图片之间的过渡，不改变每几分钟轮播一次的间隔。

## 壁纸与轮播

- 「设置 → 背景 → 壁纸」浏览并选择打包的照片。
- 「设置 → 背景 → 轮播」选择固定，或每 1 / 5 / 15 / 30 分钟。
- 选照片与选择轮播模式相互独立。要固定一张照片，选择照片后把轮播设为固定。
- 默认依然是每 5 分钟轮播。升级会保留原来固定/轮播模式、已选照片和间隔。
- 轮播仅在照片首页显示时计时；设置页、全部应用、外部 App、纯色背景会暂停，回到首页重新开始间隔。
- 当前没有联网图库或电视端文件导入；自带照片或构建时打包的图片均可使用。

## 布局与图标

列表上下选择应用，向右进入操作区；Dock 左右选择入口，向上进入操作区；在首尾继续向外按不会跳离 Dock。列表右侧操作按上下移动，向左回到上次应用；Dock 的操作移到右上角，左右选择，向下回到上次应用。列表和 Dock 共用相同首页顺序。

Dock 使用接近屏幕全宽的圆角毛玻璃底板。六个默认入口居中排列，图标为 58dp；更多入口保留图标大小，在固定底板内横向滚动。选中项超出可见边缘时，图标队列会平滑移动，保证该项完整可见；向回选择则反向移动。整条底板的背景始终与壁纸对齐，不随图标队列滑动。

图标模式使用统一的单色 SVG 标记：PlayStation、Apple TV 和哔哩哔哩来自 Simple Icons；投屏、相册、首页和操作按钮来自 Phosphor Fill。SVG 无损转换为 Android 矢量资源，统一视口、透明度和视觉尺寸。没有专属标记的其他应用使用统一应用符号，不再混用彩色方形图标。仅图标时，聚焦项会显示名称。这里没有任意上传/更换图标的功能。

## 字体与焦点

字体来自电视的 Android 系统；具体字形取决于固件，中文由系统回退。没有附带 CleanFrame 私人版付费字体。字体风格用于首页名称、操作区和时钟，设置页保持系统字体。字号选项用于纵向列表，Dock 使用适合卡片的固定字号。

毛玻璃从当前壁纸生成真实高斯模糊材质，按焦点所在位置裁切，与背后的画面对齐。列表选中块随文字、图标和 HDMI 标签宽度包裹，没有描边；柔和、浓雾、清透分别使用不同模糊程度。材质在后台线程以 384×216 分辨率生成并缓存，移动焦点只裁切，不逐帧模糊。

设置页采用圆角浅色焦点、纵向选项、弱化说明文字和圆角嵌入式预览。浏览壁纸时整页背景同步变换；返回会恢复已应用照片。

## 首页内容

从「首页内容」选择一个入口，可上移、下移或隐藏。隐藏只从本桌面移除，不卸载电视上的应用。「添加入口」包含可启动应用，以及被移除的默认信号源入口。

首页至少一项，最多九项。列表和 Dock 超出可见区域时随遥控器焦点滚动。「撤销上一步」撤销本次打开设置后的编辑；退出设置后清空撤销历史，已保存顺序保留。

首次升级保持原六个入口；此后使用本地保存的顺序。PS5 / Apple TV 是默认名称，不代表自动识别硬件；端口和机型适配仍遵循 XiaomiControls。

## 与 CleanFrame 的关系

参考其[设置交互说明](https://github.com/nthnclrk/CleanFrame/blob/fa537d1892b71d2de2bf94c24cbff3812e9f70d5/docs/interaction-behaviour.md)的分组、预览、确认应用和返回层级，在原生 Android 控件中重新实现。没有复制 Tizen 运行代码、Samsung Art Mode、付费字体或上游照片。

此设置更新没有修改公共版的开机策略、Home 角色、系统启动目标或权限。私人电视已经验证的待机修复仍单独保留；不能据此认为公开 v0.3.0 包支持待机自动进入。
